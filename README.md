# HTTP and HTTPS

A simple study note comparing **HTTP (Hyper Text Transfer Protocol)** and **HTTPS (Hyper Text Transfer Protocol Secure)**.

## Overview

HTTP and HTTPS are used to send data between a web browser and a server.

The main difference is that HTTP sends data in plain text, while HTTPS adds an encryption layer to protect data while it travels over the internet.

## HTTP vs HTTPS

| Feature | HTTP | HTTPS |
|---|---|---|
| Full Form | Hyper Text Transfer Protocol | Hyper Text Transfer Protocol Secure |
| Main Purpose | Used to send data between browser and server | Used to send data securely between browser and server |
| Data Security | Sends data in plain text | Encrypts data for security |
| Security | Data can potentially be read while travelling over the internet | Encryption helps protect data from being read or stolen |
| Port Number | 80 | 443 |
| Website Trust | May give users an indication that the website is not secure | Uses SSL/TLS certification to establish a secure connection |

## Why HTTPS is Important

HTTPS plays an important role when websites handle sensitive information such as:

- Login credentials
- Bank credentials
- Other sensitive data

HTTPS adds an encryption layer that helps protect information while it travels over the internet.

## Key Takeaways

- **HTTP** uses port **80**.
- **HTTPS** uses port **443**.
- HTTP sends data without the encryption layer provided by HTTPS.
- HTTPS uses **SSL/TLS** to provide a secure connection.
- HTTPS is especially important when websites handle sensitive information.
